# Двоичная арифметика

Исследовательская работа по теме "Двоичная арифметика в алгоритмах"

## Структура проекта

-"conversions.py" — функции преобразования чисел (десятичная, двоичная, Q8.8)
- "arithmetic.py" — арифметические операции через битовые сдвиги (сложение, вычитание, умножение, деление)
- "test_all.py" — итоговая проверка всех алгоритмов

## Как запустить

1. Убедитесь, что установлен Python 3.8 или выше
2. Откройте терминал в папке проекта
3. Запустите команду:
   python test_all.py

Все тесты должны пройти со статусом [OK].
